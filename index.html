02 / FINANCIAL PLANNING · 3-STAGE PIPELINE
INVESTMENT RISK & RETIREMENT PLANNING

A connected 3-stage Python pipeline that mirrors a real financial advisory workflow. Stage 1: a 6-factor questionnaire scores client risk tolerance and outputs a Conservative / Moderate / Aggressive classification. Stage 2: the suggested stock/bond/cash allocation is stress-tested against 5 years of live market data via the yfinance API — calculating Sharpe ratio, annualized volatility, and correlation across asset classes. Stage 3: a Monte Carlo engine runs 10,000 simulations projecting 30-year retirement outcomes, capturing sequence-of-returns risk that simple average-return models miss entirely.

Python yfinance API Monte Carlo NumPy Matplotlib Sharpe Ratio Asset Allocation

"Risk score drives allocation, allocation maps to a stress-tested retirement scenario, and real correlation data shows what that allocation actually diversifies against."
